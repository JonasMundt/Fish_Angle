# Fish Angle

Fish Angle is a hand-drawn 2D fishing game developed in Unity and C#.

Catch different fish, sell your catches, upgrade your equipment and explore deeper parts of the lake where mysterious crystal creatures have begun to appear.

## Features

- Four different fish species
- Fishing minigame
- Equipment upgrades
- Fish collection
- Two underwater zones
- Save system
- Main menu and pause menu
- Sound effects and background music
- Hand-drawn artwork

## Controls

- WASD - Move
- E - Interact / Fish
- ESC - Pause

## Technologies

- Unity 6
- C#
- Clip Studio Paint

## About the Project

Fish Angle was developed as a portfolio project with a focus on gameplay systems, progression, UI, game feel and hand-drawn 2D visuals.

The project includes systems for fishing, fish spawning, inventory management, upgrades, collections, dialogue, saving and loading, audio, and menu navigation.
